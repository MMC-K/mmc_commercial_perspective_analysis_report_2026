# 상용 서비스 관점의 복합대화 기술 성능 분석서

이 저장소는 **복합대화 연구용 데이터셋**을 활용하는 HAECHI 계열 모델과 복합대화 체험 서비스의 성능을 상용 서비스 관점에서 분석한 기술문서를 제공합니다.

## 문서

[상용 서비스 관점의 복합대화 기술 성능 분석서 V.1 (PDF)](<./상용 서비스 관점의 복합대화 기술 성능 분석서 V.1 (기술문서).pdf>)

작성: 조병길 연구원(KETI) · 버전 1.0 · 2026년 11월 18일 · 12쪽

## 목적과 내용

이 문서는 문화재 교육, 박물관 도슨트, 공공기관 OCR 업무 지원에 복합대화 기술을 적용할 수 있는지 살펴봅니다. 실제 구현·측정한 결과와 향후 적용을 가정한 사례를 구분해 설명합니다.

- **대화 체험:** 문화재 창작 서비스에서 물건·색감·재료·문양을 고르는 81개 대화 경로의 단계 진행과 답변 내용 적합성을 분석합니다.
- **시각 이해:** Qwen3.5-KETI-HAECHI-27B와 HyperCLOVA-X-KETI-HAECHI-32B의 학습 전후 국가유산 명칭 식별 및 한국어 OCR 결과를 비교합니다.
- **서비스 운영:** 모델 응답 시간과 동시 요청 시험을 바탕으로 실제 서비스에서의 대기 시간과 개선 과제를 정리합니다.

관련 자료는 [복합대화 연구용 데이터셋 안내 저장소](https://github.com/MMC-K/MMC2_MMC_RESEARCH_DATA)에서 확인할 수 있습니다.
